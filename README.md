# Simple Password Generator
Simple function that generates a robust password and saves it in a json file with an email/username and website/app with it.

## How to use it

When running the program, the program will print options to the terminal. Choose the options to change some settings for the password and/or generate the password.

You can change:
- Length of the password
- Whether to include just lower case, upper case or both in your password
- Whether to allow special characters in your password
- Any characters/letter you wish to exclude from the password

After generating the password, you have the option to save it (providing a website/app name and a username for it) or generate a new password.
Other options include:
- Listing all the passwords
- Removing a certain password from the list
- Changing the password, username and/or website/app for a specific password (search is case sensitive)
- Clearing the entire list and starting anew
